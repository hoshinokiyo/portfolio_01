1 サイト構造図

Webサイト構造図 必須
トップページから下層ページまでの階層構造を、採用担当向け導線と求職者向け導線が分かる形で整理

このサービスは、採用担当と求職者の双方が利用するため、共通ページを起点にしつつ、「採用担当向け導線」と「求職者向け導線」に分けて構造を整理した。採用担当は「人を探す → 人となりを理解する → 面談につなげる」流れ、求職者は「登録する → 自分の人となりを整理する → 公開する」流れで利用する設計としている。

Webサイト構造図

トップページ
├─ サービス紹介ページ
├─ 採用担当向け導線
│  ├─ 採用担当向け利用ガイドページ
│  ├─ 転職者プロフィール一覧ページ
│  │  └─ 転職者プロフィール詳細ページ
│  │     ├─ ひととなりストーリーページ
│  │     └─ ポートフォリオページ
│  └─ お問い合わせページ
├─ 求職者向け導線
│  ├─ 転職者登録ページ
│  ├─ プロフィール作成ページ
│  ├─ ひととなりストーリー作成・編集
│  ├─ ポートフォリオ登録・編集
│  └─ プレビュー / 公開確認
└─ お問い合わせページ

共通ページを最上位にまとめたうえで、採用担当側は「一覧から探す → 詳細で理解する → 問い合わせや面談へ進む」流れ、求職者側は「登録する → プロフィールを整える → ストーリーとポートフォリオを公開する」流れが自然に見えるように整理している。

Webアプリケーション構造図 必須
Spring Bootアプリケーションの画面構造を、共通画面と役割別画面が分かる形で整理

このWebアプリケーションは、採用担当と求職者の双方が利用するため、共通画面を起点にしつつ、「採用担当向け画面」と「求職者向け画面」に分けて構造を整理した。採用担当は「候補者を探す → 人となりを理解する → 面談につなげる」流れ、求職者は「登録する → 自分の情報を編集する → 公開する」流れで利用する設計としている。また、Spring Bootによる実装を想定し、ログイン後に役割別の画面へ遷移する構成とした。 

Webアプリケーション構造図

共通画面
├─ トップ / ランディング画面
├─ ログイン画面
├─ 新規登録画面
└─ お問い合わせ画面

採用担当向け画面
├─ 採用担当ダッシュボード
├─ 転職者プロフィール一覧画面
│  └─ 転職者プロフィール詳細画面
│     ├─ ひととなりストーリー画面
│     └─ ポートフォリオ画面
├─ 面談依頼・問い合わせ画面
└─ 利用ガイド画面

求職者向け画面
├─ 求職者ダッシュボード
├─ プロフィール編集画面
├─ ひととなりストーリー編集画面
├─ ポートフォリオ編集画面
├─ プレビュー / 公開確認画面
└─ 登録情報確認画面

将来想定の管理画面
├─ ユーザー管理
├─ プロフィール管理
├─ ポートフォリオ管理
└─ 問い合わせ管理

共通画面を入口に置き、ログイン後に役割ごとの主要導線へ分岐する構成にすることで、採用担当は「一覧から候補者を確認し、詳細を見て面談依頼へ進む」流れ、求職者は「プロフィール・ストーリー・ポートフォリオを編集して公開確認へ進む」流れが分かりやすい構成としている。管理画面は将来拡張として下位に整理し、今回の主要導線から切り分けている。

2 ページ一覧

Webサイト ページ一覧 必須

このページ一覧は、採用担当と求職者の双方の利用導線を整理したものである。採用担当は「候補者を探す → 詳しく知る → 面談につなげる」流れ、求職者は「登録する → 自分の人となりを整理する → 企業に伝える」流れで利用することを想定している。

No. ページ名 ページの目的 主要コンテンツ
1 トップページ サービスのコンセプトを伝え、採用担当と求職者の双方に興味を持ってもらう キャッチコピー、サービス概要、特長、利用の流れ、導線ボタン
2 サービス紹介ページ サービスの仕組みや特徴、既存サービスとの違いを理解してもらう コンセプト、解決する課題、主な特長、利用メリット、競合との差別化
3 転職者プロフィール一覧ページ 採用担当が候補者を検索・閲覧できるようにする プロフィールカード一覧、検索・絞り込み、おすすめ人材、詳細ページへのリンク
4 転職者プロフィール詳細ページ 採用担当が候補者の人柄や価値観を詳しく理解できるようにする 自己紹介、人となり、価値観、経歴、スキル、キャリアの希望、ストーリー・ポートフォリオへの導線
5 ひととなりストーリーページ 候補者の経験の背景や仕事観をストーリー形式で伝え、人物理解を深める キャリアストーリー、仕事観、人生の転機、働くうえで大切にしていること
6 ポートフォリオページ 候補者の制作物や実績だけでなく、思考プロセスも伝える 制作物一覧、プロジェクト概要、担当範囲、課題と解決方法、工夫した点、学び
7 転職者登録／プロフィール作成ページ 求職者が自分のプロフィールや人となり情報を登録・編集できるようにする アカウント登録、プロフィール入力、人となり入力、価値観入力、プレビュー機能
8 採用担当向け利用ガイドページ 採用担当がサービスの使い方や活用方法を理解できるようにする サービス利用方法、人材検索方法、面談依頼の流れ、活用イメージ
9 お問い合わせページ ユーザーからの問い合わせやサポート依頼を受け付ける 問い合わせフォーム、よくある質問、サポート連絡先

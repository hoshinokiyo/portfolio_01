1 デザインコンセプト

デザインコンセプト 必須

人となりを自然に伝え、理解と納得を生む採用体験を設計するUI/UXデザイン

ロゴデザイン 必須

「と」と「な」に人の出会いの喜びを、「.ai（ドットアイ）」には“会い・逢い・合い・愛”とAIの意味を重ね、サービスのコンセプトを象徴するロゴとして設計。

デザインキーワード 必須
デザインの方向性を表すキーワード3つとその説明
キーワード 説明
構造化（Structuring） タグ・見出し・カード・CTAを体系的に配置し、情報を段階的に理解できるUIを設計。ユーザーが迷わず「人となり」に到達できる導線を構築している。
信頼性（Credibility） 配色・余白・タイポグラフィを整え、ビジネスサービスとして安心して利用できる印象をつくる。
人物理解（Human Insight） 経歴情報だけでなく、価値・背景・ストーリーが伝わる設計により、面接前の理解を深める。

フォーム要素 必須
テキスト入力・セレクト・テキストエリア・チェックボックス・ラジオボタン（実物のHTMLサンプル付き）

フォーム要素は単なる入力UIとしてではなく、AIとの対話を通じてユーザー理解が深まっていく過程そのものをデモとして設計している。 また、回答内容をトリガーにプロフィールのイラストや背景表現が変化する仕組みを取り入れることで、入力から可視化までを一体化したUXとして構築した。

観点 短い説明
UI 直感的に操作でき、迷わず回答できるシンプルな入力構成
UX 回答内容が次画面の表現変化につながる体験設計
特徴 フォーム入力を自己理解を深めるプロセスとして設計
技術設計 回答内容をトリガーに、背景・イラスト・テーマを動的に切り替える構造
評価ポイント 入力から表示変化までを一連の体験として設計している点
A

ビジネス寄りのプロフィール表現

B

分析を軸にしたプロフィール表現

C

興味・個性を活かしたプロフィール表現

カード・テーブル・その他 必須
項目 実装内容 役割・意図 UX上の効果
タグ Heroや一部UIに配置したラベル要素 情報の意味や特徴を短く直感的に伝える 一目で内容を理解しやすい
イラスト Heroやプロフィール表現に使用 人となりやテーマの違いを視覚的に表現する 印象が残りやすく、理解が深まる
カード indexページHeroエリアのイラスト上に配置 メインメッセージを補足し、視線誘導を行う 情報の理解を自然に補助できる
利用規約・プライバシーポリシーのアラート クリック時に確認メッセージを表示 必須確認事項を見落とさないようにする 入力前の安心感と注意喚起につながる
初期設定時コメント デモ開始時に入力欄付近へ補助文を表示 最初の行動を迷わず始められるようにする 入力ハードルを下げる
トリガー外選択時アラート 想定外の選択時に補助メッセージを表示 デモの分岐条件を自然に案内する 誤操作時も迷いにくい
「はい」以外選択時アラート 条件に合わない選択時に再案内する 意図した体験導線へ戻せるようにする 体験の流れを崩しにくい

5 レイアウトルール

レイアウト基本ルール 必須
グリッド・余白・角丸・シャドウ等の数値ルール

全体はmax-w-7xl中心で中央寄せし、CTAのみmax-w-5xl、余白はpx-6、主要セクションはpy-24〜32、カードはp-8〜12、gap-6/8/12を基準とする。レイアウトは2・3・12カラムを使い分け、角丸はrounded-xl〜3xlと40px級、影は0 12px 32px rgba(...,0.06)前後の薄い設定で統一している。
